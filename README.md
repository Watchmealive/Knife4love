# watchmealive.tv — GitHub Pages

Hisako's complete static website. Includes the custom cursors, animated images, Rickroll MP4, solitaire, music box, name popups, and roaming kitten.

## Upload

1. Extract the ZIP.
2. Upload the files inside it to your GitHub repository. `index.html` must be in the repository root, with `assets/` next to it.
3. In the repository, open **Settings → Pages**.
4. Set the source to **Deploy from a branch**, select your branch (usually `main`) and **/ (root)**, then save.
5. GitHub will display your website URL when publication finishes.

No installation, build command, or Node server is required. Asset paths are relative, so the site also works at a repository subpath.

Guestbook notes and solitaire progress save in each visitor's browser only. The name-popup field is never saved or sent to a server. A shared guestbook requires a separate backend.

The included video is played locally in the popup; YouTube embedding is not used. The animated kiss appears after Victor's letter closes. The kitten returns after a page reload or reopening.
